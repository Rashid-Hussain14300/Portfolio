# Datta Engineering Associates Website

This is a static GitHub Pages-ready website.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js` and the `assets` folder to the repository root.
3. Open repository **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. GitHub will show your live website URL after deployment.

No npm, build process or server is required.
